# Pool Visualization

## Overview

Specifies the pool visualization and management layer, implemented in **mapeo_pool** (Flask API + React frontend + PostgreSQL). This layer provides a real-time web view of modem, SIM, and SimBank status, consuming data generated by mp_simclient. It is the presentation layer over the same physical hardware that mp_simclient controls.

## Relationship with mp_simclient

| Aspect | mp_simclient | mapeo_pool |
|--------|-------------|------------|
| Role | Hardware control (write) | Visualization (read/display) |
| Stack | Pure Python, serial, CSV | Flask + React + PostgreSQL |
| Data | Generates CSV, lista_pos.json, numero_simid.txt | Consumes and visualizes that data |
| Execution | Command line, production loops | Web server, browser access |

**They are complementary layers**: mp_simclient controls the hardware; mapeo_pool displays the state.

## Components

### Backend — Flask API

Flask web server that exposes REST endpoints to query pool state.

**Main endpoints:**

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/pools/<pool_name>` | Get current state of a pool |
| GET | `/api/pools/<pool_name>/session/<session_name>` | Get data for a specific session |
| GET | `/api/pools` | List all available pools |

### Frontend — React

React web interface that renders a **visual grid** of each modem's state in each pool.

**Features:**
- Modem grid: each cell represents a modem (column) of a SimBank.
- Color-coded by state (registered, unregistered, error, empty).
- Tooltip information: phone number, ICCID, carrier, signal.
- Periodic state refresh.

### Database — PostgreSQL

`db1` PostgreSQL database that stores pool state history. (See Session Management spec for schema details.)

## Pool Data Structure

### dict_nodo.json

JSON file that defines the node topology for mapeo_pool. Maps control ports (SimBank) to modem ports:

```json
{
  "COM19": ["COM3", "COM5", "COM7", "COM9", "COM11", "COM13", "COM15", "COM17"],
  "COM20": ["COM23", "COM25", "COM27", "COM29", "COM31", "COM33", "COM35", "COM37"]
}
```

**Nomenclature:**
- Key: `pool_com` — SimBank control port.
- Value: Array of `slot_com` — modem ports linked to that SimBank.

### Visual Grid

The grid is organized as:
- **Rows**: SimBanks (pool_com).
- **Columns**: Modems (slot_com) within each SimBank.
- **Cell**: Current state of the modem (active SIM, number, CREG, signal).

```
Pool: nodo-santiago-01

         COM3   COM5   COM7   COM9   COM11  COM13  COM15  COM17
COM19  [ OK ]  [ OK ]  [ERR]  [ OK ]  [ OK ]  [---]  [ OK ]  [ OK ]
         COM23  COM25  COM27  COM29  COM31  COM33  COM35  COM37
COM20  [ OK ]  [ERR]  [ OK ]  [ OK ]  [ OK ]  [ OK ]  [---]  [ OK ]
```

## Cell States

| State | Visual | Meaning |
|-------|--------|---------|
| registered | Green | Modem registered on network, SIM operational |
| unregistered | Yellow | Modem has SIM but no network registration |
| error | Red | Serial communication or hardware error |
| empty | Gray | No SIM or empty slot |
| switching | Blue | SIM change in progress |
