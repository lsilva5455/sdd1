# Configuration

## Overview

Specifies the system's configuration system, including the two configuration file formats (`config.json` for mp_simclient and `dict_nodo.json` for legacy mapeo_pool), operational parameters, performance thresholds, and format conversion between them.

## Configuration Formats

### config.json — mp_simclient Format (Primary)

Primary format and source of truth. Hierarchical structure defining SimBanks, columns, and operational parameters.

```json
{
  "nodo": "N99",
  "simbanks": {
    "COM19": {
      "columns": {
        "1": "COM3",
        "2": "COM5",
        "3": "COM7",
        "4": "COM9",
        "5": "COM11",
        "6": "COM13",
        "7": "COM15",
        "8": "COM17"
      }
    },
    "COM20": {
      "columns": {
        "1": "COM23",
        "2": "COM25",
        "3": "COM27",
        "4": "COM29",
        "5": "COM31",
        "6": "COM33",
        "7": "COM35",
        "8": "COM37"
      }
    }
  },
  "filas": 16,
  "baudrate": 115200,
  "cambio_fila_minutos": 30,
  "sim_intento_operativo": 5,
  "max_workers": 16,
  "sdata_iteraciones": 2,
  "switch_wait_seconds": 3.2,
  "reboot_stabilization_seconds": 15,
  "network_registration_first_seconds": 20
}
```

### dict_nodo.json — Legacy Format (mapeo_pool)

Simplified format used by mapeo_pool. Contains only topology (no operational parameters).

```json
{
  "COM19": ["COM3", "COM5", "COM7", "COM9", "COM11", "COM13", "COM15", "COM17"],
  "COM20": ["COM23", "COM25", "COM27", "COM29", "COM31", "COM33", "COM35", "COM37"]
}
```

## Operational Parameters

### Identity

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `nodo` | String | — | Node identifier for this deployment (e.g., "N99"). Displayed in the startup banner and used to distinguish between multiple mp-core instances |

### Topology

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `simbanks` | Object | — | SimBank mapping with their columns and ports |
| `filas` | Integer | 16 | Number of SIM rows per SimBank |
| `baudrate` | Integer | 115200 | Serial communication speed for all ports |

### Production Timing

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `cambio_fila_minutos` | Integer | 30 | Duration of each production round in minutes |
| `switch_wait_seconds` | Float | 3.2 | Wait time after sending AT+SWIT before continuing |
| `reboot_stabilization_seconds` | Integer | 15 | Wait time after modem reboot for stabilization |
| `network_registration_first_seconds` | Integer | 20 | Timeout for first network registration attempt |

### Operational Thresholds

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `sim_intento_operativo` | Integer | 5 | Maximum registration attempts per SIM before switching |
| `max_workers` | Integer | 16 | Maximum parallel threads for port processing |
| `sdata_iteraciones` | Integer | 2 | Number of complete hardware scan iterations |

### Staggered Wait (Derived)

Calculated parameter, not explicitly configured:

```
staggered_delay = (column_number - 1) * 3  // seconds
```

- Column 1: 0s, Column 2: 3s, Column 3: 6s, ..., Column 8: 21s.
- Purpose: Avoid RF jamming when multiple modems boot simultaneously.

## Format Conversion

### dict_nodo.json → config.json

Converter available at: `utils/json_sadmin_mp_simclient/convert_dict_to_config.py`

**Conversion logic:**

1. For each key (pool_com) in dict_nodo.json:
   - Create entry in `simbanks` with pool_com as key.
   - For each slot_com in the array:
     - Assign sequential column number (1, 2, 3, ...).
     - Map column → slot_com.

2. Operational parameters are added with default values.

```python
# Pseudocode
for pool_com, slot_coms in dict_nodo.items():
    config["simbanks"][pool_com] = {
        "columns": {
            str(i+1): slot_com 
            for i, slot_com in enumerate(slot_coms)
        }
    }
```

### config.json → dict_nodo.json

Reverse conversion (simplification):

```python
dict_nodo = {
    pool_com: [columns[str(i)] for i in sorted(columns.keys())]
    for pool_com, data in config["simbanks"].items()
    for columns in [data["columns"]]
}
```

## Configuration Validation

### Validation Rules

1. **Non-empty SimBanks**: Each SimBank must have at least 1 column.
2. **Sequential columns**: Columns must be numeric and sequential (1, 2, 3...).
3. **Unique ports**: Control ports and modem ports cannot be repeated.
4. **Valid baudrate**: Must be a standard value (9600, 19200, 38400, 57600, 115200).
5. **Positive rows**: `filas` must be >= 1.
6. **Positive times**: All time parameters must be > 0.
7. **Reasonable workers**: `max_workers` must be >= 1 and <= total number of modems.

## Runtime State Files

In addition to static configuration, the system generates state files at runtime:

| File | Generated by | Consumed by | Description |
|------|-------------|-------------|-------------|
| `slot_state.json` | SlotManager | SlotManager | Current circular rotation index |
| `lista_pos.json` | DataManager | SlotManager | Valid positions for production |
| `numero_simid.txt` | DataManager | SimClient | Phone-to-ICCID mapping |
| Scan CSV | DataManager | mapeo_pool | Complete data from last scan |
