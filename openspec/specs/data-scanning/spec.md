# Data Scanning

## Overview

Specifies the hardware scanning and data management subsystem, implemented in the `DataManager` class (`data_manager.py`, 1728 lines). This module performs complete hardware scans to discover which SIMs are present, collect their data (ICCID, phone number, signal), save results to CSV, and generate the output files needed for production.

## Key Concepts

### Hardware Scan

A systematic reading process of all positions (rows x columns) of all SimBanks to discover which SIMs are present and which are operational.

### Output Files

Scanning produces multiple files consumed by other system components:
- **Scan CSV**: Complete data for each SIM found.
- **numero_simid.txt**: Phone-to-ICCID mapping for SimClient.
- **lista_pos.json**: Valid positions for SlotManager.

## Scanning Process

### Parallel Scanning Per Row

The DataManager scans **one row at a time**, processing all columns of that row **in parallel** using `ThreadPoolExecutor`:

```
Row 1:  [Col1, Col2, Col3, Col4, Col5, Col6, Col7, Col8] → parallel (max_workers)
Row 2:  [Col1, Col2, Col3, Col4, Col5, Col6, Col7, Col8] → parallel
...
Row 16: [Col1, Col2, Col3, Col4, Col5, Col6, Col7, Col8] → parallel
```

**Iterations**: The scan is repeated `sdata_iteraciones` times (default: **2**) to improve result reliability.

### Per-Column Sequence (within a row)

For each position (SimBank, column, row):

1. **Switch SIM**: Send `AT+SWIT{col}-{row:04d}` to the SimBank.
2. **Wait for stabilization**: `switch_wait_seconds` (3.2s).
3. **Reboot modem**: Based on model (EC25/UC20).
4. **Wait for stabilization**: `reboot_stabilization_seconds` (15s).
5. **Read CCID**: `AT+CCID` → get ICCID.
6. **Verify registration**: `AT+CREG?` → network status.
7. **Read signal**: `AT+CSQ` → RSSI level.
8. **Record result**: Save to internal data structure.

### Progressive CSV Saving

Results are saved **progressively** during scanning:
- After each complete row, the CSV file is updated.
- If the process is interrupted, data from already-scanned rows is not lost.
- The CSV is overwritten on each complete iteration (not appended).

## Post-Scan CCID Verification

After the complete scan, the DataManager executes a CCID verification:

1. Compares the read ICCID with the expected ICCID (from previous scans or database).
2. Mismatches are sent to `CCIDAnalyzer` for diagnosis.
3. The diagnosis can indicate:
   - **Wrong port**: The ICCID is found in a different modem port. May indicate a wiring error.
   - **Wrong column**: The ICCID corresponds to another column in the same SimBank. May indicate a switching error.
   - **Wrong row**: The ICCID corresponds to another row. May indicate the SimBank didn't switch the row correctly.
   - **Timing issue**: The previous ICCID is still present; the switch didn't have enough time to complete.

## Monitoring Queue (Unregistered SIMs)

The DataManager maintains a monitoring queue for SIMs that failed to register during scanning:

- SIMs with `CREG ≠ 1/5` are added to the queue.
- The queue can be queried later for retries or exclusion.
- Persistently unregistered SIMs are excluded from `lista_pos.json`.

## Output Files

### Scan CSV

CSV file with complete data for each scanned slot:

| Field | Description |
|-------|-------------|
| simbank | SimBank control port (e.g., COM19) |
| column | Column number (1–8) |
| row | Row number (1–16) |
| iccid | ICCID of the SIM read |
| phone | Phone number (if available) |
| creg | Network registration status (0/1/2/3/5) |
| csq | RSSI signal level |
| status | Scan status (ok/error/empty) |

### numero_simid.txt

Text file with phone-to-ICCID mapping, consumed by SimClient:

```
56912345678,8956091234567890123
56987654321,8956011234567890123
56911111111,8956031234567890123
```

### lista_pos.json

List of valid positions for production, consumed by SlotManager. Generated by calling `generate_slot_pos` which applies the 5 validation filters (see Slot Management spec).

## File Mirroring

The DataManager implements **file mirroring**: copies generated output files to remote or backup locations. This ensures other system components (e.g., mapeo_pool) have access to the most recent data.

## Statistics Collection

The DataManager collects scan statistics:

- Total SIMs found.
- SIMs with successful vs failed registration.
- SIMs by carrier (WOM, ENTEL, CLARO, MOVISTAR).
- SIMs with CCID mismatch.
- Total scan time.
- Success rate per SimBank/column.

## CCIDAnalyzer

Auxiliary module (`ccid_analyzer.py`, 192 lines) that diagnoses ICCID discrepancies:

### Diagnosis Types

- **Wrong Port**: The found ICCID corresponds to another modem port. Indicates a possible wiring error.
- **Wrong Column**: The ICCID corresponds to another column of the same SimBank. May indicate a switching error.
- **Wrong Row**: The ICCID corresponds to another row. May indicate the SimBank didn't switch the row correctly.
- **Timing Issue**: The previous ICCID is still present; the switch didn't have enough time to complete.
- **Unknown SIM**: The ICCID doesn't correspond to any known SIM in the system.

## Relevant Configuration Parameters

| Parameter | Default Value | Description |
|-----------|---------------|-------------|
| `sdata_iteraciones` | 2 | Number of complete scan iterations |
| `max_workers` | 16 | Parallel threads for scanning |
| `switch_wait_seconds` | 3.2 | Post-switch wait during scanning |
| `reboot_stabilization_seconds` | 15 | Post-reboot wait during scanning |
| `filas` | 16 | Number of rows to scan per SimBank |
